# 📅 Dynamic Semester Planner Dashboard (Microsoft Excel)

A dynamic Excel-based semester planner featuring an interactive dashboard, automated calendar generation, KPI tracking, event management, and monthly analytics.

---

## 📖 Overview

This project was developed to simplify semester planning by combining an interactive calendar, dashboard, and event management system into a single Excel workbook.

The planner automatically updates calendars, KPIs, charts, holidays, and events based on the selected month, making it easy to monitor the semester at a glance.

---

## ✨ Features

- 📅 Dynamic monthly calendar
- 📊 Interactive dashboard
- 🎯 Semester progress tracker
- 📌 Upcoming holidays and events
- 📈 KPI cards for:
  - Total Days
  - Working Days
  - Weekends
  - Holidays
  - Events
- 🍩 Dynamic doughnut chart
- 🔄 Automatic month switching using dropdown menus
- ⚡ Formula-driven automation (no manual updates required)
